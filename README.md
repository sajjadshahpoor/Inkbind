# Inkbind

**Bind your documents together — or take them apart.**

Inkbind is an all-in-one PDF toolkit for editing, merging, splitting, and organizing your documents. Built for speed and simplicity, it handles everyday PDF workflows without the bloat.

## Features
- ✂️ **Split** — break large PDFs into individual pages or custom ranges
- 🔗 **Merge** — combine multiple PDFs into one document
- ✏️ **Edit** — annotate, add text, insert or remove pages
- 🔄 **Convert** — (planned) PDF ↔ Word, images, and more
- 🔒 **Secure** — (planned) password protection and encryption
